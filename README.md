- Full-stack, backend, cloud and DevOps skills
- Featured NexoraAI and AI-Enabled Garage Finder projects
- Education, experience and certifications
- Direct GitHub, LinkedIn and email links
- Mobile-responsive design
- Resume PDF included in `assets/`

## Deploy to GitHub Pages
1. Create/update the `Portfolio` repository.
2. Upload `index.html` and the `assets/` folder.
3. In GitHub: **Settings → Pages → Deploy from branch**.
4. Select the branch/folder containing `index.html`.
